# עדכון שבועי במייל

סקריפט של Google Apps Script שרץ מחשבון הגוגל של רועי כל מוצאי שבת (בסביבות 20:40),
קורא את הנתונים מ-Firebase ושולח מייל לרועי ולמייל של בת הזוג שבהגדרות האפליקציה.

התקנה חד-פעמית:
1. script.google.com ← New project.
2. מדביקים את `Code.gs` במקום הקוד הקיים.
3. Project Settings ← מסמנים "Show appsscript.json" ← מדביקים את `appsscript.json`.
4. מריצים את `setup` פעם אחת ומאשרים הרשאות.
5. מריצים את `sendNow` כדי לקבל מייל לדוגמה.
