# החתונה של רועי ונטע

אפליקציה לתכנון החתונה: משימות, תקציב, אולמות, ספקים, מוזמנים ומתנות.

- `index.html`: האפליקציה (עמוד אחד).
- `platform.js`: התחברות עם גוגל, נתונים ב-Firebase, וחיבור ליומן ולדרייב.
- `firebase-config.js`: מזהי הפרויקט ב-Firebase (לא סודיים; הגישה לנתונים נעולה בכללי האבטחה).
- `sw.js`, `manifest.webmanifest`, `icons/`: התקנה למסך הבית ועבודה בלי רשת.

הנתונים עצמם לא נמצאים כאן. הם ב-Firebase, וזמינים רק לשני חשבונות הגוגל של הזוג.
